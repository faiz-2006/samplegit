# Northstar Market

A simple ecommerce storefront built with plain HTML, CSS, and JavaScript.

## Project structure

```text
opensource-bug-hunt-ecommerce/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── images/
```

## Run locally

From this project folder, start a simple static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Features

- Responsive storefront layout
- Product grid with category filters
- Search input for filtering products
- Shopping cart drawer with quantity controls
- Total price updates in real-time
- Clean modern ecommerce styling

## Notes

This demo uses remote Unsplash images to make the storefront visually rich without extra setup.
